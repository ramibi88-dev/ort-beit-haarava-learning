אורט בית הערבה - מרכז הלמידה

מבנה:
index.html - האתר
css/style.css - עיצוב
js/app.js - מנגנון המבחנים
data/english.json - מאגרי אנגלית
data/financial.json - מאגרי חינוך פיננסי
data/subjects.json - רשימת מקצועות

לעדכון שאלות יש לערוך רק את קובץ ה-JSON המתאים ולהעלות מחדש.
לבדיקה מקומית יש להפעיל שרת HTTP, למשל: python3 -m http.server 8000
ואז לפתוח http://localhost:8000
